# 实验 12 实测

模型与计划来自实验 07/08，CPU 使用同一冻结 GBDT `learned`，SSD 回迁 `always`。GPU 32 MiB、CPU 14 MiB、SSD 4 GiB，实际 GPU 18 槽、CPU 8 槽，每块 1.75 MiB。盘层是 WSL ext4 上的 `O_DIRECT`，宿主 WSL 虚拟盘位于 NVMe SSD。实写采用 Linux 服务进程树 `write_bytes` 差；计数包含审计等文件写入，未测设备 NAND 写入量。

## 冻结 78 条：两种写法均无盘回读

轮 0 按 `eager → on_evict`，轮 1 反序。四组预热和正式生成 token 逐项一致，也与实验 08 对应负载一致。时间为 ms，TTFT 列为中位数 / P95，槽等待为总计 / 单次峰值。每组 CPU 峰值 8 槽、同时用作 SSD 写源的峰值 7 槽、CPU 淘汰 56 块。
