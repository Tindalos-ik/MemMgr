# SciFact 检索问答回放结果

## 数据与复用

独立 Chroma 索引了完整 SciFact 的 5,183 篇文献（6,854 个文本块）。用固定 BGE 在官方测试集的 48 条抽样问题上检索，文档 Recall@3 为 0.696。问题、证据及聊天模板来自真实语料和项目代码；复访次数及顺序是受控设计，未使用真实用户流量。

六条独立序列各含 8 条首次出现的不同问题和 10 条复访。策略和序列执行顺序各反转一次；每序列清空 GPU、CPU 与策略历史。三策略均分配 32 MiB GPU KV（18 块）和 56 MiB CPU KV（32 块），每块 64 token。`admission` 和 `learned` 共用实验 06 的冻结模型与阈值 `0.35`。三个策略及两轮共 648 条生成请求，逐位置核对了输入与输出；共核对 27,948 个实际输出 token ID，完全一致。

每策略正反两轮合计：不同问题段 84/96 条请求命中同一个 64-token 系统模板块，CPU 回迁为零，没有跨问题的更长前缀命中。复访段 120 条请求都有 GPU 命中；量化结果如下。

| 策略 | CPU 命中请求 / 120 | GPU + CPU 复用超过 64 token 的请求 / 120 | CPU 回迁 token | 两段合计 CPU 写入 MiB |
| --- | ---: | ---: | ---: | ---: |
| `lru` | 69 | 77 | 29,568 | 3,048.50 |
| `admission` | 36 | 54 | 23,296 | 269.50 |
| `learned` | 36 | 54 | 23,296 | 269.50 |

两种模型策略的 216 对请求在准入块数、命中、重算、迁移和淘汰计数上逐条相同；两组均未淘汰 CPU 块，`learned` 的 216 次保留判断均接受。`lru` 淘汰了 1,358 块，其中 1,084 块在该次驻留期间未被 CPU 回迁读取。

## TTFT 与策略开销

客户端配对差值单位为毫秒，按相同顺序阶段、序列和请求位置计算处理组减对照组。括号内为 95% 区间，按六条独立序列整簇抽样 5,000 次；同一序列的正反两轮一起抽样。P95 是逐对差值的 P95。

| 请求段 | 比较（处理 − 对照） | 中位数 [95% 区间] | P95 [95% 区间] |
| --- | --- | ---: | ---: |
| 不同问题 | `admission − lru` | −74.60 [−104.12, −64.20] | 41.10 [−21.56, 63.92] |
| 不同问题 | `learned − lru` | −84.21 [−99.06, −58.55] | 43.05 [−30.14, 84.48] |
| 不同问题 | `learned − admission` | −4.69 [−13.31, 8.47] | 75.59 [29.87, 121.04] |
| 受控复访 | `admission − lru` | −19.78 [−44.25, −8.47] | 55.32 [42.85, 106.66] |
| 受控复访 | `learned − lru` | −20.25 [−43.24, −3.84] | 80.09 [40.10, 89.89] |
| 受控复访 | `learned − admission` | −4.95 [−9.93, 2.99] | 64.46 [40.97, 86.01] |
| 全部 | `admission − lru` | −56.28 [−70.65, −30.36] | 54.79 [39.37, 63.92] |
| 全部 | `learned − lru` | −50.80 [−80.93, −26.23] | 77.97 [39.63, 89.89] |
| 全部 | `learned − admission` | −4.70 [−11.08, 4.50] | 74.90 [36.89, 106.72] |

每请求策略开销，单位为微秒，表列中位数 / P95。统计包含未调用阶段的零值；保留列计入写入筛选，淘汰单列。计时扣除了内层重复计时和审计写入。

| 策略 | 特征 | GBDT 评分 | 保留/筛选 | 淘汰 |
| --- | ---: | ---: | ---: | ---: |
| `lru` | 38.56 / 87.54 | 0 / 0 | 8.10 / 24.63 | 10.23 / 27.70 |
| `admission` | 50.20 / 102.59 | 546.14 / 1,356.30 | 6.34 / 16.58 | 0 / 0 |
| `learned` | 48.89 / 123.03 | 527.97 / 1,663.63 | 23.94 / 68.16 | 0 / 0 |

`learned − admission` 的复访客户端中位差正序为 +5.26 ms，反序为 −8.58 ms；两组缓存动作逐请求相同，样本也没有触发 `learned` 的竞争淘汰。此次回放无法证明额外保留策略改善 TTFT。两种模型策略相对 `lru` 的客户端中位差为负，复访的差值 P95 为正；观察差异伴随明显不同的 CPU 写入量。正反顺序中 `admission` 都位于中间，六序列区间不涵盖跨机器或真实流量变化。

原始输入：`.agent/kv-scifact/prepared/inputs.json`。请求、审计和原始指标快照：`.agent/kv-scifact/replay/`。客户端与服务端各组绝对 TTFT、配对差及按顺序拆分的结果：`.agent/kv-scifact/evaluation/review.json`；逐请求开销和复用记录：同目录的 `per_request.jsonl`。
