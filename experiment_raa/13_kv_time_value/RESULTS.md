# 实验 13：CPU KV 保留时间价值

## 真实历史离线回放

实验 08 `pressure-14` 的首轮 CPU `learned` 审计，包含 1 条预热和 50 条正式请求。所有策略接收相同的键链，使用实验 06 冻结 GBDT。反事实计算假定 GPU 冷、CPU 写入立即完成。时间系数单独取实验 06 的真实配对校准：1 块、8 块各 4 对，重算减 CPU 回迁的服务端 TTFT 中位差为 15.896、40.196 ms；实测 GPU→CPU 写入估计为 1.303 ms/块。历史校准 CPU 容量 32 块，历史回放只有 8 块；该估计仅用于离线回放。

| 策略 | CPU 写入块 | CPU 淘汰块 | CPU 命中 token | 前缀重算 token |
| --- | ---: | ---: | ---: | ---: |
| `admission` | 81 | 73 | 11,392 | 15,283 |
| `learned` | 81 | 73 | 10,816 | 15,859 |
| `time_value` | 18 | 10 | 3,200 | 23,475 |

`time_value` 的 39 次计价中有 29 次缩短或拒绝写入；相对 `learned` 少写 63 块，多重算 7,616 token。此处不报告端到端 TTFT：CPU 命中为基于真实历史输入的反事实。

原始结果：`.agent/kv-time-value/historical/{review.json,pilot.json,time_value.jsonl}`。

## 正式未见 CPU 评价

每组 88 条正式请求，含 24 条复访，另有 1 条预热。三组的输入、冻结 GBDT 准入以及正式请求的 704 个输出 token ID 逐一一致，预热的 8 个输出 token 也一致。`learned` 首次运行在第 38 条正式请求的解码阶段出现 CUDA `unknown error`；保留原始记录，配对使用独立重采的完整组。

| 策略 | 服务端 TTFT 中位数 / P95（ms） | 客户端 TTFT 中位数 / P95（ms） | CPU 写入 / 读回（块） | CPU 写入 / 读回 DMA（ms） | 重算 token |
| --- | ---: | ---: | ---: | ---: | ---: |
| `admission` | 127.68 / 489.14 | 130.47 / 491.32 | 112 / 28 | 159.80 / 22.38 | 33,112 |
| `learned` | 124.61 / 472.99 | 127.86 / 484.07 | 96 / 32 | 116.85 / 20.91 | 32,856 |
| `time_value` | 126.91 / 472.49 | 130.06 / 478.27 | 56 / 32 | 120.89 / 20.70 | 32,856 |

配对差为处理组减对照组，先逐请求相减；P95 为差值的最近秩。以下“路径不同”指该窗口里读写块数、命中或重算量至少一项不同的配对数。

`time_value` 的 62 次计价里有 60 次缩短或拒绝；计划淘汰的 41 块与实际事件逐一一致。相对 `learned` 少写 40 块（70 MiB，−41.7%），全体读回和重算总量持平，GPU 命中也均为 18,432 token。累计 CPU 写入 DMA 时间反而多 4.04 ms。计价审计的总估计收益为 1,196.76 ms，扣除写入 56.37 ms 和受害块机会成本 617.49 ms 后为 522.90 ms；此和仅描述策略所用估值，不能解释为节省了对应的实际 TTFT。

三组 SSD 逻辑读写均为 0。进程树 Linux 实读均为 0，实写分别为 294,912 / 327,680 / 368,640 字节，含审计与日志等进程文件 I/O。`time_value` 的全体配对 P95 和两组对照下的复访 TTFT 都恶化，当前数据不支持默认启用。三组各成功采集一次，运行时间段不同，TTFT 可能受设备状态变化影响。

本次 GPU 结论仅限上述设备的单序列 CPU-only 压力回放。正式 connector 支持从已发布的 SSD 副本取替代路径成本，但未采集新策略的 SSD GPU 三组对照；CPU profile 不能用于 SSD。未校准 `on_evict`、并行序列或混合层几何。
